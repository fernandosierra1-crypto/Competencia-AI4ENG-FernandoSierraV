## 📁 Contenido del repositorio

Este repositorio contiene los notebooks desarrollados durante las entregas del curso, siguiendo la estructura requerida:

### 🔍 **01 - exploración.ipynb**  
Análisis inicial del conjunto de datos, revisión de estructura, valores faltantes, estadísticas básicas y visualizaciones preliminares.

### 🧹 **02 - preprocesado.ipynb**  
Limpieza, imputación, transformación y construcción del conjunto de datos preprocesado.

### 🤖 **03 - modelo con preprocesado de tal forma y SVM.ipynb**  
Primera aproximación de modelado utilizando un pipeline de preprocesado y un modelo SVM.

### 🌲 **04 - modelo con preprocesado de otra forma y Random Forest.ipynb**  
Segunda aproximación utilizando un preprocesamiento alternativo y un modelo Random Forest.

### 🏆 **99 - modelo solución.ipynb**  
Notebook final que genera la solución oficial enviada a Kaggle.  
Incluye: carga de datos, preprocesamiento definitivo, entrenamiento del modelo final y exportación del archivo `.csv`.
